# SoundWave — Discover new music

SoundWave — учебный midterm-проект: адаптивная одностраничная витрина для знакомства с музыкой, исполнителями и плейлистами. Интерфейс сайта выполнен на английском языке.

Проект работает в браузере и использует HTML, CSS, Bootstrap и JavaScript без сборщика и серверной части.

## Возможности

- Карусель с beabadoobee, 5 Seconds of Summer и Ariana Grande.
- Карточки исполнителя The 1975, альбома AM и плейлиста Late Night Drive.
- Раздел Trending с вкладками All, Indie и Pop, а также статический список New releases.
- Подборки по настроению: Calm, Focus и Energy.
- Светлая и тёмная темы; выбор сохраняется в `localStorage` под ключом `sw-theme`, если хранилище доступно.
- Закреплённый мини-плеер: выбор композиции, Play/Pause, предыдущий и следующий трек, обложка и индикатор времени.
- Форма подписки с проверкой email и обязательного согласия.
- Адаптивная сетка и мобильное меню, подписи для элементов управления, видимый фокус и поддержка уменьшения анимации.

## Ограничения демоверсии

- **Звук не воспроизводится.** Плеер моделирует прогресс таймером; для всех композиций задана демонстрационная длительность 3:45. Аудиофайлов и музыкального API в проекте нет.
- Поле поиска отображается, но поиск и фильтрация не реализованы.
- Форма подписки проверяет ввод и показывает сообщение в браузере. Она не отправляет данные, не сохраняет подписчиков и не рассылает письма. Переключатель Weekly/Monthly не влияет на обработку формы.
- Ссылки Explore с `href="#"` служат заглушками. Кнопки Explore в карусели ведут к разделу Artists.
- Содержимое музыкальных подборок задано в HTML и автоматически не обновляется.

## Технологии

- HTML5 и CSS3: CSS-переменные, адаптивная сетка Bootstrap, медиазапросы и анимация.
- JavaScript без дополнительных библиотек: DOM, события, таймер и `localStorage`.
- Bootstrap 5: локальные файлы в `css/` и `js/`; при ошибке их загрузки предусмотрен CDN fallback на версию 5.3.3. Заголовок локального CSS указывает версию 5.3.8.
- Google Fonts: DM Sans и Fraunces, с резервными системными шрифтами.
- Локальные JPG-изображения и встроенные SVG-иконки.

## Запуск

### Без установки зависимостей

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте его:

   ```sh
   git clone https://github.com/gaipovasevara01-source/midterm.git
   cd midterm
   ```

2. Откройте `index.html` в современном браузере.

Node.js, npm, база данных, API-ключи и настройка переменных окружения не требуются. Сохраняйте структуру папок, чтобы относительные пути к стилям, скриптам и изображениям работали.

### Через локальный HTTP-сервер

Если установлен Python 3, выполните из папки проекта:

```sh
python -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Чтобы остановить сервер, нажмите `Ctrl+C`.

Интернет используется для Google Fonts и, при необходимости, CDN fallback Bootstrap. При наличии локальных ресурсов сайт может работать без этих загрузок с резервными шрифтами.

## Как устроен мини-плеер

`script.js` собирает уникальные пары названия и исполнителя из элементов с атрибутами `data-track` и `data-artist`. Нажатие на такую кнопку выбирает трек и запускает демонстрационный таймер. По завершении 3:45 плеер переходит к следующему треку по кругу.

Кнопка Previous сбрасывает время текущего трека, если прошло больше трёх секунд; иначе выбирает предыдущий трек. Next выбирает следующий. Кнопки Previous и Next сохраняют текущее состояние воспроизведения или паузы.

Путь к обложке строится из названия: нижний регистр, только латинские буквы и цифры, затем `.jpg` в папке `images/`. Например, `Ever Seen` → `images/everseen.jpg`. Если изображение не загрузилось, используется исходная обложка Ever Seen.

## Изменение содержимого

- Редактируйте тексты, карточки и списки композиций в `index.html`.
- Для новой кнопки выбора трека укажите `data-track` и `data-artist`, а обложку добавьте по правилу выше.
- Цвета и параметры тем находятся в начале `style.css`.
- Поведение плеера и форм находится в `script.js`.

## Ручная проверка

После изменений можно проверить:

1. Мобильное меню, переключение слайдов и вкладок Trending.
2. Переключение темы и её восстановление после перезагрузки при доступном `localStorage`.
3. Выбор трека, смену обложки, Play/Pause, Previous/Next и движение индикатора времени без звука.
4. Отклонение неверного email или отсутствующего согласия и сообщение после корректного ввода.
5. Отображение страницы на узком и широком экране, а также навигацию клавишей Tab.

В репозитории нет настроенного набора автоматических тестов или команды сборки.
